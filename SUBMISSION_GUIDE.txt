FIITMeteo Binary Protocol - SUBMISSION GUIDE
================================================================================

REQUIRED FILES FOR SUBMISSION:
------------------------------

Your xmiklosz.zip package must contain exactly 4 files:

1. server.py          - The binary protocol server
2. tester.py          - The binary protocol tester
3. fiitmeteo.lua      - The Wireshark dissector
4. xmiklosz.pdf       - Documentation (convert DOCUMENTATION.md to PDF)


HOW TO CREATE SUBMISSION PACKAGE:
---------------------------------

Step 1: Convert Documentation to PDF
   You need to convert DOCUMENTATION.md to xmiklosz.pdf

   Options:
   a) Use pandoc (if installed):
      pandoc DOCUMENTATION.md -o xmiklosz.pdf --pdf-engine=xelatex

   b) Online converter:
      - Upload DOCUMENTATION.md to https://www.markdowntopdf.com/
      - Download as xmiklosz.pdf

   c) Use markdown editor:
      - Open DOCUMENTATION.md in VSCode, Typora, or similar
      - Export as PDF → save as xmiklosz.pdf

Step 2: Run Submission Script
   ./create_submission.sh

   This will create xmiklosz.zip with the 4 required files.


MANUAL CREATION (if script fails):
----------------------------------

If the script doesn't work, create manually:

   zip xmiklosz.zip server.py tester.py fiitmeteo.lua xmiklosz.pdf

Verify contents:
   unzip -l xmiklosz.zip

Should show:
   server.py
   tester.py
   fiitmeteo.lua
   xmiklosz.pdf


TESTING BEFORE SUBMISSION:
--------------------------

UAT1 - Basic Registration:
   Terminal 1: python3 server.py (select 2)
   Terminal 2: python3 tester.py (select 2)
   Result: All 4 sensors register and send data

UAT2 - Battery Warning:
   With tester running: select 4, choose sensor, answer 'a' for battery
   Result: Server shows "WARNING: LOW BATTERY"

UAT3 - CRC Error:
   With tester running: select 5, choose sensor
   Result: Server detects CRC error, client resends

UAT4 - Disconnect:
   With tester running: select 6, choose sensor
   Result: Server detects timeout, sends PINGs, client reconnects

UAT5 - ACK Timeout:
   Server: type 'uat5', enter sensor name
   Result: Client retries, server ACKs on 4th attempt
